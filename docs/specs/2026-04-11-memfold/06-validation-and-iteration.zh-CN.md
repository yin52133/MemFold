# 06 Validation And Iteration

## 1. 目的

这份文档定义 MemFold 的验收方法。

这里的 `TDD` 不是给文档写关键字检查脚本，而是：

- 先定义失败样例
- 再定义预期行为
- 再定义验收方法
- 最后才允许进入实现

如果一个能力无法先写出失败样例和通过条件，这个设计就还不够能施工。

## 2. 验收模板

每个核心能力都必须用同一模板描述：

1. `能力目标`
2. `失败样例`
3. `预期行为`
4. `测量方法`
5. `通过门槛`
6. `失败后的回退动作`

## 3. 核心能力验收

### 3.1 稳定载入

- 能力目标：相同输入得到相同加载结果
- 失败样例：
  - 未完成 mutation 时出现部分可见
  - `fresh` 错读旧记忆
  - `sterile` 触发隐式回忆
- 预期行为：
  - 相同快照下 `load` 输出确定性一致
  - 模式隔离严格生效
- 测量方法：
  - 对同一快照重复执行 `load`
  - 对 mutation 中间态做故障注入
- 通过门槛：
  - item 集合一致
  - 顺序一致
  - token 裁剪一致
  - 不出现部分可见
- 回退动作：
  - 等待稳定点或显式降级为只读加载

### 3.2 快速索引检索

- 能力目标：常见查询足够快，且回指稳定
- 失败样例：
  - rename 后回指失效
  - 删除后旧索引仍命中
  - 增量同步产生重复命中
- 预期行为：
  - 查询在门槛内返回
  - 返回结果能稳定回指真相源
- 测量方法：
  - 热路径查询基准
  - 混合检索基准
  - rename/delete/reindex 故障样例
- 通过门槛：
  - 热路径：`p50 < 50ms`，`p95 < 150ms`
  - 混合检索：`p50 < 150ms`，`p95 < 400ms`
- 回退动作：
  - 禁止增量同步，切回全量重建

### 3.3 错误记忆不可复活

- 能力目标：被拒绝 claim 不能换壳回来
- 失败样例：
  - 换 summary 重新晋升
  - 换 observation 重新晋升
- 预期行为：
  - tombstone 生效
- 测量方法：
  - 构造同义 claim 重新导入
- 通过门槛：
  - 自动晋升率为 0
- 回退动作：
  - 强制进入人工复核

### 3.4 Dreaming 不自我污染

- 能力目标：模型反思不能直接变长期记忆
- 失败样例：
  - reflection note 被当 observation 晋升
- 预期行为：
  - reflection note 默认不可晋升
- 测量方法：
  - 构造纯反思输入
- 通过门槛：
  - 晋升率为 0
- 回退动作：
  - 关闭相关输入通道

### 3.5 敏感信息不入库

- 能力目标：敏感原文不进长期层与实验层
- 失败样例：
  - token/cookie/private key 出现在 JSONL、Markdown、SQLite、QMD、benchmark
- 预期行为：
  - 只保留标签、摘要或引用
- 测量方法：
  - 敏感样例集注入
- 通过门槛：
  - 原文泄漏率为 0
- 回退动作：
  - 触发 redaction 与级联清理

### 3.6 删除传播

- 能力目标：删改和脱敏能级联传播
- 失败样例：
  - archive 删除后 QMD 仍命中
  - backup 仍保留旧原文
- 预期行为：
  - 真相源、投影、索引、缓存一致
- 测量方法：
  - 删除/脱敏后做全链路查询
- 通过门槛：
  - 不再命中旧内容
- 回退动作：
  - 强制 repair + full reindex

## 4. TDD 式设计收敛

设计阶段也走三步：

### 4.1 RED

先定义失败样例。  
如果只能描述“理想状态”，不能描述“怎么失败”，设计还不够具体。

### 4.2 GREEN

只给出最小能通过验收的机制，不提前加复杂度。

### 4.3 REFACTOR

在保证验收不退化的前提下压缩设计、合并模块、减少状态和减少 token 消耗。

## 5. 20 轮 autoresearch 设计迭代

这 20 轮不是 20 次随意改稿，而是 20 次围绕失败样例和门槛的定向迭代。

### 5.1 轮次 1-5：加载与污染

1. boot 编译规则
2. mode 隔离
3. source gating
4. token 预算裁剪
5. 错误记忆复活防护

### 5.2 轮次 6-10：索引与回指

6. QMD 文档模型
7. 热路径查询
8. 增量同步
9. 全量重建
10. rename/delete 后回指稳定性

### 5.3 轮次 11-15：跨存储一致性

11. mutation 状态机
12. 崩溃恢复
13. repair 顺序
14. 锁与并发
15. 备份与恢复

### 5.4 轮次 16-20：dreaming 与安全

16. observation ingress gate
17. reflection note 隔离
18. dreaming promotion precision
19. sensitive redaction propagation
20. experiment/prod hard isolation

## 6. 每轮产出要求

每一轮都必须产出：

- 失败样例列表
- 当前机制说明
- 验收方法
- 通过/失败结果
- 是否进入下一轮

如果没有失败样例和验收方法，只是在写说明文，不算有效迭代。

# MemFold 参考库与致敬

这份文档不讨论“借了谁的代码”，只记录对 MemFold 有启发的公开项目，以及它们各自做得好的地方。

| 项目 | 值得学习的点 |
|------|--------------|
| `OpenClaw` | 把记忆分层、把 dreaming 单独提出、让长期记忆可审查 |
| `QMD` | 本地索引、collection 组织、把检索层独立出来 |
| `Hermes Agent` | 把记忆系统看成有生命周期边界的独立能力 |
| `Codex Autoresearch` | 用迭代实验而不是主观感觉来改系统 |
| `MemPalace` | 追溯层的重要性，提醒我们不要只看“当前最短上下文” |
| `llm-wiki-skill / llm-wiki-agent` | 背景知识页和主题页应该独立于长期记忆层 |

MemFold 的取向不是复制这些项目，而是吸收其中真正清晰、可落地的部分。

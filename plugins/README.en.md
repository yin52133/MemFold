# Plugins

[中文](./README.zh-CN.md) | [English](./README.en.md)

This directory is the single plugin source for MemFold in Codex.

Current contract:

- runtime skills live only under `plugins/memfold/skills/`
- command definitions live only under `plugins/memfold/commands/`
- other projects should install the plugin instead of copying isolated skill files
